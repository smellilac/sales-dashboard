# AI Notes 
 
- Основным coding-agent был Claude Code. 
- AI использовался для реализации задач после определения технического направления. 
- Перед реализацией крупных задач агент сначала готовил план, а код писался после внесения правок по плану и последующего подтверждения. 
- Принятые архитектурные решения фиксировались и не пересматривались без необходимости. 
- В течение разработки код проверялся через анализаторы Meziantou, SonarAnalyzer, Roslynator, xUnitAnalyzer, build, tests, а также с ограничением TreatWarningsAsErrors — данные ошибки Claude Code исправлял самостоятельно. 
- AI использовался не только для генерации кода, но и для обсуждения архитектурных решений и их trade-offs; окончательный выбор оставался за разработчиком. 
- Бизнес-логика и ключевые архитектурные решения сначала обсуждались и уточнялись вручную, после чего передавались Claude Code для реализации. 
- Для отдельных задач Claude Code получал явные ограничения: что реализовывать, что не трогать и какие решения считать settled или Draft. 
- Предложения AI проверялись вручную; при необходимости решения изменялись или отклонялись. 
- Для backend отдельно проверялись SQL-запросы, тесты и корректность аналитических расчётов. 
- AI помогал декомпозировать разработку на отдельные задачи и определять порядок их реализации.
